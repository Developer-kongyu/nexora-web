# 高保真前端实现清单

本次实现以 `design-reference/png_preview` 中的 31 张 1440 × 1024 高保真图、`design-reference/页面补充说明.md`、路由映射和后端模块边界为基准。页面 15 在输入文档中已删除，未建立无意义的空路由。

## 1. 应用外壳与设计系统

- 固定侧边导航、顶部搜索、移动端底部导航和主工作区布局。
- 统一设计令牌：品牌渐变、背景、边框、阴影、圆角、排版、过渡与响应式断点。
- 共享组件：Button、IconButton、Card、Avatar、Badge、TextField、Select、Switch、Modal、Toast、EmptyState、PageHeader、Spinner。
- 基础按钮默认 `type="button"`，表单提交显式使用 `type="submit"`，避免嵌套表单误提交。
- 路由页面按需加载；公共认证壳、Onboarding 壳、登录后应用壳分离。

## 3. 业务交互闭环

核心写操作均通过领域 API 与 TanStack Query Mutation 组织，并在 MSW 中提供同路径契约：

- 认证：密码/验证码登录、注册、找回、重置、Google 补全和刷新会话。
- 内容：发布、草稿发布/删除、评论、评论点赞、帖子删除。
- 用户关系与资料：关注、取关、取消待审批请求、入站请求审批、粉丝/关注 cursor 列表、静音/屏蔽 owner 管理列表与解除操作；资料编辑先读取 B02 owner view，媒体经 B05 READY 后再提交 B02 storage key。
- 收藏：收藏夹增删改、批量移动、移除失效内容。
- 内容中心：已发布、草稿与已删除正式列表；后端未开放恢复/永久清理时只读展示，不伪造写操作。
- 社群：正式 DTO 创建、媒体上传、加入/退出、申请审批、成员、置顶、规则、审计和七字段设置管理。
- 隐私：影响预览和策略保存。
- 通知/偏好：通知配置、兴趣标签、未读摘要与实时 bootstrap。
- 浏览历史：单条删除、批量删除和清空。

写操作包含加载态、成功反馈、失败反馈；关注、加入、点赞等适合即时反馈的操作实现乐观更新和失败回滚。

## 4. 状态与数据边界

- `TanStack Query`：列表、详情、未读计数、设置、Mutation 与缓存失效。
- `Zustand`：认证会话和帖子媒体上传队列；头像/封面使用页面生命周期内、可恢复且文件绑定的检查点状态。
- `React Hook Form + Zod`：认证、资料编辑和发布表单。
- `MSW`：开发、Vitest 和 Playwright 共用 fixtures/handlers，避免三套假数据协议漂移。
- `shared/api/client.ts`：唯一底层 `fetch` 入口，负责 envelope 解包、超时、AbortSignal、认证头、401 单飞刷新、幂等键和统一错误。

## 5. 响应式与状态设计

- 桌面端按 240px 导航、主信息流和辅助栏组织；中等宽度折叠导航；移动端切换底部导航和单列内容。
- 列表页包含 loading、empty、error 和无筛选结果状态。
- Modal、Toast、按钮 loading/disabled、表单 field error 形成统一反馈体系。
- 图片提供 alt，图标按钮提供 aria-label；搜索输入、文件输入和无可见文字的复选框补充可访问名称。
